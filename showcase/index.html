How well can an agent shop?

WebShop gives an agent a request written by a person, such as “blue wireless headphones under $40”, and a store of real products. The agent searches, reads pages, picks options and buys. Every square here is one of the 500 test requests, shaded by how well the chosen agent's purchase matched it.

    How a purchase is scored

    The store scores a purchase by checking it against the request, part by part. Try it with a real request written by a crowd worker for the WebShop dataset: mark what the bought product got right and watch the score change.

    Attribute the product must have Option to select before buying
    • A wrong option costs nothing. Choosing the wrong size scores the same as choosing none, so the agents added to raise the score always select the closest option in every group.
    • Product type multiplies everything. If the product is the wrong kind of thing, the whole score falls, however well the details match.

    All thirteen agents, side by side

    All 13 agents were trained and evaluated in one Kaggle run on two T4 GPUs, on the same 500 requests and the full store. The last four were added after a first run, to see how far the score could be raised. The whiskers show 95% bootstrap intervals over requests.

    Where the points come from

    The share of each part of the reward that each agent earned. Options count as zero on the 109 requests that name no options, so no agent can reach 100 in that column.

    Training on two T4 GPUs

    Imitation learning (IL) taught a BERT policy from human demonstrations. Reinforcement learning with A2C then fine-tuned it, or started from pretrained BERT alone. All numbers come from the logs of the Kaggle run.

    Imitation accuracy

    How the value shopper decides

    The best agent learns one thing: how much buying a product will score. It learned this from 65,948 simulated purchases on 2,000 training requests, using 33 features of what a shopper can see on the pages. Then it compares many products before buying. Select a stage to see where it falls in an episode.

    1. Search twiceOnce with a query predicted from the request, once with the request itself.
    2. Read two results pages for each searchUp to 40 products, noting each title, price and position.
    3. Shortlist by titleA 16-feature model ranks every product seen. This takes no steps.
    4. Open the most promising productsUp to 14, each with its features and description pages: six steps per product, as many as the step limit allows.
    5. Score each oneThe full 33-feature model estimates what buying it would score.
    6. Return to the best and buySelect the closest option in every group, then buy. Twelve steps are always kept back for this.

    The 100-step limit

    One square per step. An average test episode used 85.1 of them; the agents trained with A2C used 3 to 10. The split between stages is drawn from the agent's design, not measured per episode.

    Settings were chosen on validation requests

    Requests 500 to 1,499, never the test requests. Opening more products helped, and so did learning attribute phrases such as “long lasting”.

    What these numbers don't show

    The best agent is not deep RL
    The value shopper is a linear value estimate on hand-designed features, with fixed navigation. The A2C agents remain the project's main RL result.
    It took far more steps
    About 85 steps per request against 3 to 10 for the trained agents. The reward has no cost per step, so this is allowed, but the budgets differ.
    The test requests were used more than once
    Two faults were found after the first test runs of the added agents and every run was repeated. Settings never changed, the Kaggle run matched the last laptop run exactly, and all runs are listed in the report.
    Retrained agents moved between runs
    The whole pipeline ran twice on Kaggle, the first time with older code. The fixed rule scored the same in both, but the retrained agents moved by up to 15 points: greedy IL rose from 34.6 to 49.4. This page shows the second run.
    Imitation learning stopped early
    Both seeds reached the 60-minute limit during epoch 7 of 10, so the IL policy may be underfitted.
